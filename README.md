# Curso Ley 30936

Sitio de presentación para exponer, en clase y a pantalla completa, los alcances de la **Ley N.º 30936**, que promueve y regula el uso de la bicicleta como medio de transporte sostenible.

Fuente del texto: SPIJ H1234001 / *El Peruano* del 24 de abril de 2019.

## Cómo dictar el curso

```bash
export PATH="$HOME/.local/node/bin:$PATH"
npm install
npm run dev
```

Abra la URL local, pulse **Pantalla completa** (o la tecla `F`) y recorra las láminas:

- `←` `→` o `AvPág` / `RePág`
- `I` índice
- `Home` / `End` primera y última lámina
- `Esc` sale de pantalla completa

Cada lámina está pensada en 16:9. El índice permite saltar, por ejemplo, al artículo 7 (estacionamientos) o al 10 (derechos).

## Compilar

npm run build
npm run preview
